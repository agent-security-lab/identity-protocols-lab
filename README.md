# identity-protocol-labs

Hands-on labs for OAuth 2.x, OIDC, SCIM, token exchange and MCP authorization, run against a local Keycloak. Synthetic data only.

## Quick start

```
docker compose up
```

Admin console: http://localhost:8080 (admin / admin, throwaway lab credentials).
